Extracted verbatim from https://www.rfc-editor.org/rfc/rfc7541.txt on 2026-08-19.
Captured for subsystem C task C0. Together with Appendix C.6, these are the
ONLY published Huffman test vectors in either RFC 7541 or RFC 9204 - RFC 9204
reuses the table without restating any vectors, so there is nowhere else to
check a Huffman encoder against. Ground truth for C's Huffman codec tests.
These are HPACK examples, so their surrounding representation octets and their
index values are HPACK's, NOT QPACK's. Only the Huffman-coded string literals
inside them transfer: the header-block framing, the dynamic table state shown
after each request, and every table index in these examples are HPACK and must
not be copied into a QPACK implementation.
This RFC predates the unpaginated RFC text format; see the note in
rfc7541-appendix-b-huffman-code.txt on page furniture.

C.4.  Request Examples with Huffman Coding

   This section shows the same examples as the previous section but uses
   Huffman encoding for the literal values.

C.4.1.  First Request

   Header list to encode:

   :method: GET
   :scheme: http
   :path: /
   :authority: www.example.com
